# Salary Radar

A clean personal budget monitor for tracking monthly salary, bills, shopping, Visa card spending, savings, and daily safe spending.

## Features

- Monthly salary input
- Transaction tracking by category
- Bills, Shopping, Visa Card, Food, Transport, Savings, and Other categories
- Remaining balance calculation
- Spending percentage
- Savings percentage
- Daily safe spend for the rest of the month
- Visual doughnut chart
- Money mood warnings and tips
- Local browser storage
- Export budget data as JSON
- Monthly transaction reset

## Hosting with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save.

Your site should appear at:

`https://mrcopra.github.io/ai-site/`
